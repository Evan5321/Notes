### ② 词性与含义连线

| 后缀 | 词性 |
| ---- | ---- |
| ‑erate　（使…） | 抽象名词 |
| ‑sis / ‑esis / ‑osis　（过程/病症） | 动词 |
| ‑ius　（属于…的） | 名词（过程、事件、状态；病症） |
| ‑iture　（动作产生的结果/权利） | 形容词 或 专有名词 |

## 答案与解析

### 题型一

1. gener　再生　（re‑ 再次 + gener 生 + ‑erate 使 → 使再次产生）
2. de‑　退化　（de‑ 向下 → 向下走 → 退化）
3. e‑　蒸发　（e‑ 出 + vapor 蒸汽 → 使变成蒸汽散去）
4. mod　节制；缓和　（控制在合适尺度）
5. 坏　恶化，衰败　（使变坏）
6. 拆开；lys　分析　（拆开 + 松开 → 拆解剖析的过程）
7. 旁；lys　瘫痪　（旁 + 松解 → 身体失控松弛）
8. 在下方；放置　假设　（预先设立的观点）
9. 净化　宣泄，情感净化
10. fibr　纤维化　（纤维增生病变）
11. halit　口臭　（气息异常）
12. rad　半径　（射线一样的线段）
13. aqu　水瓶座；水之守护者
14. 最先；gen　长子继承权　（最先出生带来的制度）
15. 授予　授权，就职典礼　（in‑ 加强 → 授予职位/权力的仪式）
16. 过量；fac　（sur‑ 过量 + 做 → 过量，饱足）
17. 花费　开支
18. 装备　家具

### 题型二

1. B　2. B　3. B　4. A　5. A　6. B　7. A　8. B　9. A　10. A　11. C　12. A

### 题型三

1. gener；再次；向下；生；退
2. lys；拆开；旁；分析；瘫痪
3. gen；名词（过程）；名词/形容词（特质）→ 实际考查点：‑esis 是过程名词，‑ius 是特质/人名后缀 → 天才、天赋
4. 穿戴/覆盖；加强；授予职位/权力的仪式
5. osis；气息；口臭；纤维；纤维化

### 题型四

① ‑sis：analysis、crisis、paralysis、hypothesis
　‑esis：genesis、catharsis（‑esis 变体）
　‑osis：fibrosis、halitosis、tuberculosis、necrosis

② 连线：
　‑erate → 动词
　‑sis / ‑esis / ‑osis → 名词（过程、事件、状态；病症）
　‑ius → 形容词 或 专有名词
　‑iture → 抽象名词

③ 1. 错（‑er‑ 是拉丁动词词干连接字母，本身无实义）
　2. 对　3. 对　4. 错（变形为 ‑eration：generate → generation）
　5. 错（词性为抽象名词，含义为动作产生的结果/权利/身份；"家具"表示它可用于具体实物，但后缀性质是抽象名词）

### 题型五

1. 路径：re‑(再次) + gener(生) + ‑ate(使) → "使再次产生" → v. 再生。
2. 路径：primo‑(最先) + gen(出生) + ‑it‑(连接) + ‑ure(制度) → "最先出生这件事带来的制度" → n. 长子继承权。
3. 路径：in‑(加强) + vest(授予) + ‑iture(仪式/权利) → "授予职位/权力的仪式" → n. 授权，就职典礼。
   （意象：vest 本义"穿戴"，如给官员穿上官服；对比 vestiture = 穿戴/覆盖之物。）
