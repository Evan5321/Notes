
# **‑erate / ‑sis / ‑ius / ‑iture**

## ‑erate

> 构成：**‑er‑ + ‑ate**
> `-ate` = 动词后缀（拉丁语被动/使动）；中间 `-er‑` 是拉丁动词词干连接字母，本身无实义

### ✅ 词性：**大多为动词**，含义 =「**使…；造成；产生某种动作/状态**」

### 公式：词根 + er + ate → 使……

- generate：gener(生) +‑erate → **使**产生 → v.产生
- regenerate：re‑再次 + gener +‑erate → v.再生
- degenerate：de‑向下 + gener +‑erate → v.退化
- operate：oper(工作) +‑erate → v.操作
- ameliorate /əˈmiːliəreɪt/
    amel (好) +‑erate → **使**变好 → v. 改善，改良
- deteriorate /dɪˈtɪəriəreɪt/
    deter (坏) +‑erate → **使**变坏 → v. 恶化，衰败
- evaporate /ɪˈvæpəreɪt/
    e‑出 + vapor 蒸汽 +‑erate → **使变成**蒸汽散去 → v. 蒸发；消失
- tolerate /ˈtɒləreɪt/
    toler 忍耐 +‑erate → **使**承受 → v. 容忍，忍受
- moderate /ˈmɒdəreɪt/
    mod 尺度 +‑erate → **控制**在合适尺度 → v. 节制；缓和
> 小规律：
> `-ate` 本身可以做动词/形容词；**‑erate 几乎只做动词**
> 名词变形：‑eration（generate → generation）

| 后缀    | 变形名词  |
| ------- | --------- |
| ‑erate | ‑eration |

## 2️⃣ ‑sis / 变体 ‑esis / ‑osis

> 词源：希腊语后缀 **‑σις (‑sis)**
> ✅ **词性：名词**
> 核心意思：**一个动作的过程、事件、状态；某种病症**

### 细分3种常见变体

1. **‑sis**：单纯动作/过程
   genesis = gen(出生) +‑esis → 诞生、起源
2. **‑osis**：偏向「病变、异常状态」
   necrosis 坏死，tuberculosis 结核病
3. **‑esis**：强调「诞生、发生」（和gen搭配专用）
   genesis

**‑sis**
- crisis /ˈkraɪsɪs/
    cris (决断) +‑sis → 需要做出抉择的时刻 → n. 危机
- analysis /əˈnæləsɪs/
    ana‑拆开 + lys 松开 +‑sis → 拆解剖析的过程 → n. 分析
- paralysis /pəˈræləsɪs/
    para‑旁 + lys 松解 +‑sis → 身体失控松弛 → n. 瘫痪
**‑esis**
- catharsis /kəˈθɑːsɪs/
    cathar 净化 +‑sis (‑esis 变体) → n. 宣泄，情感净化
- hypothesis /haɪˈpɒθəsɪs/
    hypo‑在下方 + thesis 放置 +‑sis → 预先设立的观点 → n. 假设
**‑osis（偏向病变、异常生理状态）**
- fibrosis /faɪˈbrəʊsɪs/
    fibr 纤维 +‑osis → 纤维增生病变 → n. 纤维化
- halitosis /ˌhælɪˈtəʊsɪs/
    halit 气息 +‑osis → 口气异常 → n. 口臭

> 形容词变化：‑tic
> genesis → genetic

## 3️⃣ ‑ius

> 拉丁语阳性形容词/名词后缀，古典拉丁后缀，**现代英语大多留在名词/人名/学术词**
> ✅ 词性：**形容词 或 专有名词**
> 本义：**属于…的；具有…性质的；人名后缀**

1. **古典人名、物种学名（生物拉丁名）**
   genius：gen(与生俱来的天赋) +‑ius
   字面：the one who is born (with gift) → 与生俱来的神灵/天赋 → n.天才，天赋
   Julius（凯撒），Aurelius
2. 形容词（古拉丁语，日常英文很少）
   proprius = proper 自己固有的

3. 特质 / 抽象名词
    - radius /ˈreɪdiəs/
        rad 射线 +‑ius → 射线一样的线段 → n. 半径
    - fungus /ˈfʌŋɡəs/（拉丁阳性‑us/‑ius 同源变体）
        fung 生长 +‑us → 滋生之物 → n. 真菌
    - bonus /ˈbəʊnəs/
        bon 好 +‑us (‑ius 同族后缀) → 好的额外奖赏 → n. 奖金
4. 古典人名 / 物种拉丁学名
    Claudius 克劳狄乌斯（古罗马帝王名）
    Aquarius /əˈkweəriəs/
    aqu 水 +‑arius (‑ius 衍生) → 水瓶座；水之守护者

> 衍生变形：‑ia /‑ium /‑ious
> genius → ingenious adj.聪明灵巧的

## 4️⃣ ‑iture

拉丁语后缀：**‑it‑ + ‑ure**
`‑ure` = 名词后缀：**动作带来的结果、状态、制度、权利**
`‑it‑` 是拉丁动词过去分词词干连接成分，无独立含义
✅ **词性：抽象名词**
含义：**由前面动作产生的结果 / 权利 / 身份 / 继承之物**

**primogeniture**
primo‑(first最先) + gen(出生) +‑it‑ +‑ure
最先出生这件事带来的制度 → **长子继承权**

- vestiture /ˈvestɪtʃə(r)/
    vest 穿戴 +‑it‑ +‑iture → 覆盖之物；服饰；（生物）被覆
- investiture /ɪnˈvestɪtʃə(r)/
    in‑加强 + vest 授予 +‑iture → 授予职位 / 权力的仪式 → n. 授权，就职典礼
- requisition（征用，征调） /ˌrekwɪˈzɪʃn/（同源‑it‑ure 家族）
    对比：acquisitive（渴望得到的、贪婪的）；
- suppositure /səˈpɒzɪtʃə(r)/
    suppos 放置 +‑iture → 假定之物，假说
- partition /pɑːˈtɪʃn/（同一拉丁分词词干‑it‑体系）
- surfeit /ˈsɜːfɪt/（古‑iture 简写形式）
    sur‑过量 + feit (=fac 做) → n. 过量，饱足
- expenditure：expend 花费 +‑iture → n.开支
- furniture：furnish 装备 +‑iture → n.家具
- departure：depart离开 +‑ure（同源结构）
